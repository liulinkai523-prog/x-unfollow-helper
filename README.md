# X 未回关助手

一个用于整理 X 关注列表的 Chrome 扩展。当前版本：V7.5，试用阶段。

![功能介绍示意图](features.png)

> 上图为功能示意，不是实际界面截图。

## 功能

- 检测你关注、对方没有回关的账号。
- 鼠标拖动连续选择或取消选择。
- 全选当前结果、取消全部选择、仅选择可取关用户。
- 一键启动已选用户的批量取关，执行前显示数量并确认。
- 单人或批量加入、移出白名单。
- 白名单导入导出、搜索及白名单专用视图。
- 互关、白名单和关系不明确的账号自动跳过取关。
- 可选认证账号保护；运行期间可以停止。

不包含粉丝数读取、筛选或万粉保护，也不包含批量回关。

## 安装

1. 下载仓库 ZIP 并解压到固定文件夹。
2. 打开 Chrome 的 `chrome://extensions`，开启开发者模式。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的文件夹。
4. 刷新 X 页面。

### 已安装旧版时更新

不要卸载原扩展。用新版 `manifest.json`、`content.js` 和 `injected.js` 覆盖原扩展目录中的对应文件，在扩展管理页面重新加载原扩展，再刷新 X。

白名单保存在 Chrome 扩展本地存储中。保持原扩展 ID，才能继续读取原数据。安装为另一个扩展 ID 时，需通过导出和导入迁移。建议更新后导出备份。

## 使用

1. 进入**你自己**的“正在关注”页面，路径为 `/你的用户名/following`。
2. 打开右下角助手，点击“拉取当前列表”。
3. 检查用户关系及每行保护原因。
4. 可按住鼠标左键从行内空白、名字或简介开始拖过多行。未选行开始表示选择，已选行开始表示取消。
5. 选择后加入白名单，或点击取关按钮。该按钮显示实际可操作数量；已选的受保护用户不会被取关。

“全选当前结果”遵循当前视图及搜索条件。“全不选”取消所有选择，包括隐藏结果。批量白名单操作包含所有已选用户，包括隐藏结果。

拖动选择未加入边缘自动滚动。运行期间不要切换账号或列表页面。停止会等待当前请求结束，不再开始下一项。

## 数据与接口

扩展在 X 页面中读取列表响应，并通过 X 网页内部接口操作。不使用独立的官方开发者 API 授权流程。

白名单及资料快照保存在 `chrome.storage.local`。代码未配置第三方数据上传服务。导出的白名单文件包含账号资料，请自行保管。

X 网页内部接口变化可能导致 404、拉取失败或关系未知。关系未知会保留。操作超时或失败后请刷新页面核对结果，避免盲目重试。
